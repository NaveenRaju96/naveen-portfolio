NAVEEN RAJU — EDITORIAL PORTFOLIO STARTER

Included:
- index.html: homepage with interactive theme filters
- style.css: responsive dark editorial design
- script.js: mobile navigation, filtering and copyright year
- stories/: six individual article/research pages

Run on Windows:
1. Extract this ZIP into a folder.
2. Open that folder in File Explorer.
3. Click the address bar, type cmd, press Enter.
4. Run: python -m http.server 8000
5. Open http://127.0.0.1:8000
