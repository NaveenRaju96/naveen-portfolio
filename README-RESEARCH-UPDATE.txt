# Naveen Raju — Updated Editorial Portfolio

This package preserves the existing portfolio and adds a dedicated **Environment, People & Change** research-notes page.

## What changed
- Added a `Research` navigation link to `research.html`.
- Added a sustainability visual-notes section to the homepage.
- Added nine supplied photographs under `images/sustainability/`.
- Added descriptive captions connecting each scene to sustainability, livelihoods, public health, environmental systems or evidence.
- Kept the existing editorial design, stories, galleries and profile.
- Added `IMAGE-CREDITS-TO-COMPLETE.csv` to record each photograph's original source and licence.

## Important editorial and academic distinction
The supplied photographs are presented as illustrative stock/reference images. They are **not** described as Naveen's own photographs, fieldwork, interviews or research evidence. The page is framed as a developing collection of visual notes and questions, not a completed research study or systematic review.

Before publishing:
1. Complete the image-credit CSV with the original photographer/source, source page and licence for every image.
2. Check that each licence permits website publication and any required attribution is displayed.
3. If any image is not licensed for reuse, replace it with an appropriately licensed image.
4. Verify factual statements against reliable sources before adding citations or presenting conclusions.
